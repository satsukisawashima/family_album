写真投稿で犬の気持ちを日記のように残す

愛犬の写真を投稿すると自動で犬の気持ちがひと言で表現され、振り返ると日記になるファミリーアルバムです。完全静的サイトなので GitHub Pages と Live Server でそのまま動作します。

アルバムを開く

このサイトでできること

  • 愛犬の写真を家族で投稿・共有
  • 投稿内容から犬の気持ちをひと言で表現
  • 写真が並ぶアルバムをいつでも確認
  • ビルドツール不要の静的 HTML/CSS/JavaScript

使い方

  1. 「アルバムを開く」をクリックして投稿ページへ移動
  2. 写真を選び、コメントを入力して投稿
  3. 投稿が一覧に追加され、犬の気持ちが記録されます

Node.js不要・ビルドツール不使用の静的サイト構成。
